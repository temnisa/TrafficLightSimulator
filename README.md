# Traffic Light Simulator

## 1. 概要

C言語で作成した車両用信号機シミュレーターです。

PC上で信号機の状態を自動的に切り替え、コンソールに現在の信号状態と経過時間を表示します。

信号機の状態管理、状態遷移、タイマー制御、周期処理、モジュール分割を学習するために制作しました。

---

## 2. 目的

本システムの目的は、車両用信号機の基本的な動作をPC上でシミュレーションすることです。

制作を通して、以下の組み込みソフトウェア開発に必要な基本的な考え方を学習しました。

* 状態遷移の設計
* タイマー制御
* 周期処理
* モジュール分割
* テスト設計

---

## 4. 主な機能

* 信号状態の自動遷移
* タイマーによる状態切り替え
* 100ms周期での処理
* 信号状態と経過時間のコンソール表示
* qキーによるシミュレーション終了

## 5. 信号状態

信号機は以下の順番で状態を自動的に遷移します。

赤 → 青 → 黄 → 赤

|信号状態|時間
|:---|:---
|赤|10秒
|青|10秒
|黄|3秒

100ms周期でタイマーを更新し、設定時間に到達すると次の状態へ遷移します。

---

## 6. モジュール構成

```
Main
├─ Signal Control 
└─ Display
```

### Main

システム全体の処理を管理します。

* 100ms周期の管理
* Signal Controlの呼び出し
* Displayの呼び出し
* qキーによる終了判定

### Signal Control

信号機の状態とタイマーを管理します。

* 信号機データの初期化
* 信号状態の管理
* タイマー更新
* 状態遷移

### Display

信号機の状態をコンソールに表示します。

* 信号状態の表示
* 経過時間の表示
