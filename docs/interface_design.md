# インターフェース設計書

## 目的

各モジュール間で利用する機能を定義する。

---

## Signal Controlモジュール

### 初期化

### 機能

信号機を初期状態にする。

### 呼び出し元

Main

### 結果

* 信号状態 = 赤
* 経過カウント = 0

---

### 信号機更新

### 機能

100ms周期で信号機のタイマーを更新し、設定時間に応じて信号状態を遷移させる。

### 呼び出し元

Main

### 結果

* 経過カウントが更新される
* 設定時間に到達した場合、信号状態が次の状態へ遷移する
* 状態遷移時に経過カウントが0になる

---

## Displayモジュール

### 信号状態表示

### 機能

現在の信号状態と経過時間をコンソールに表示する。

### 呼び出し元

Main

### 結果

* 現在の信号状態が表示される
* 現在の状態になってからの経過時間が表示される

---

## Main

### 終了操作確認

### 機能

ユーザーによるqキーの入力を確認する。

### 呼び出し元

Main

### 結果

* qキーが入力された場合、シミュレーションを終了する
* qキーが入力されていない場合、処理を継続する
