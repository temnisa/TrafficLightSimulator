
# 1. 概要

本システムは車両用信号機1基を模擬するコンソールアプリケーションである。
信号機の状態を「青・黄・赤」の3状態で管理し、一定時間ごとに状態を遷移させる。また、ユーザーが信号機の状態を確認できるように、コンソール上に現在の信号状態を表示する。

# 2. システムの目的

本システムは、車両用信号機の基本的な動作をPC上でシミュレーションすることを目的とする。

# 3. 対象範囲

対象：
* 車両用信号機1基
* 青、黄、赤の3状態
* 状態遷移
* タイマーによる自動制御
* コンソールへの状態表示

対象外：
* 歩行者用信号機
* 複数信号機
* 交差点制御
* 押しボタン
* GUI
* マイコン接続

4. 機能要件

* システム起動時に信号の初期状態を「赤」に設定する。
* 現在の信号状態を管理する。
* 100ms周期でタイマー更新する。
* 設定された時間経過に応じて信号状態を遷移させる。
* コンソール上に現在の信号状態を表示する。
* ユーザーによる終了操作を受け付ける。

5. 信号状態

赤：10秒間表示
青：10秒間表示
黄：3秒間表示

6. 状態遷移

信号状態は以下の順番で遷移する。

赤
↓ 10秒経過
青
↓ 10秒経過
黄
↓ 3秒経過
赤
↓
繰り返し

各状態への遷移条件は、現在の信号状態に設定された時間が経過した場合とする。
状態が遷移すると、経過時間を0にリセットする。

7. タイマー仕様

* システムは100ms周期で処理を実行する。
* 100msを10回実行すると1秒となる。
* 赤信号は10秒経過で青信号へ遷移する。
* 青信号は10秒経過で黄信号へ遷移する。
* 黄信号は3秒経過で赤信号へ遷移する。
* 状態遷移時に経過時間を0にリセットする。

8. 表示仕様

* 現在の信号状態を表示する。
* 現在の状態になってからの経過時間を表示する。
* 状態遷移後、経過時間を0秒から表示する。

9. 終了条件

* ユーザーがqキーを入力した場合、シミュレーションを終了する。
* qキーが入力されない場合、シミュレーションは継続する。

10. 制約事項

* C言語を使用する。
* Visual Studioを使用して開発する。
* Windows上で動作するものとする。
* PC上で完結するシステムとし、マイコンは使用しない。
* コンソールアプリケーションとして実装する。
