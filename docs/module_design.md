# モジュール設計書

## Mainモジュール

### 役割

システム全体の処理を管理する。

### 担当

* システム初期化
* 100ms周期の管理
* Signal Controlの呼び出し
* Displayの呼び出し
* qキーによる終了判定

---

## Signal Controlモジュール

### 役割

信号機の状態とタイマーを管理する。

### 担当

* 信号機データの初期化
* 信号状態の管理
* タイマー更新
* 状態遷移

### 状態遷移

赤 → 青 → 黄 → 赤

---

## Displayモジュール

### 役割

信号機の状態をコンソールに表示する。

### 担当

* 信号状態の表示
* 経過時間の表示

---

## モジュール構成
```text
Main
├── Signal Control
└── Display
```
