# テストケース一覧

## TC-001: 初期状態

### 条件

* プログラム起動する。

### 操作

* 起動直後の表示を確認する。

### 期待結果

* 信号状態が「赤」であることを確認する。

## TC-002: 信号状態の遷移

### 条件

* プログラムを起動して、信号状態が「赤」であることを確認する。

### 操作

* 信号状態と経過カウントを確認する。

### 期待結果

* 赤：100カウントで青へ遷移することを確認。
* 青：100カウントで黄へ遷移することを確認。
* 黄：30カウントで赤へ遷移することを確認。
* 状態遷移後、経過カウントが0にリセットされることを確認する。
* 赤 → 青 → 黄 → 赤の順で遷移することを確認する。

## TC-003: qキーによる終了

### 条件

* シミュレーションが実行中であることを確認する。

### 操作

* qキーを入力する。

### 期待結果

* シミュレーションが終了し、プログラムが正常に終了することを確認する。
