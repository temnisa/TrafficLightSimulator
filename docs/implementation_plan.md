# 実装計画書

## Phase 1：Signal Controlモジュール

### 実装内容

* 信号状態の定義
* 信号機データの定義
* 信号機の初期化

### 完了条件

信号機を初期状態（赤）にできる。

---

## Phase 2：タイマー・状態遷移

### 実装内容

* 100ms周期で経過カウントを更新
* 設定時間の判定
* 赤 → 青 → 黄 → 赤の状態遷移

### 完了条件

設定した時間に応じて信号状態が自動的に遷移する。

---

## Phase 3：Displayモジュール

### 実装内容

* 信号状態の表示
* 経過時間の表示

### 完了条件

現在の信号状態と経過時間をコンソールに表示できる。

---

## Phase 4：Mainモジュール

### 実装内容

* システム初期化
* 100ms周期のメインループ
* Signal Controlの呼び出し
* Displayの呼び出し
* qキーによる終了処理

### 完了条件

信号機シミュレーターを起動して、終了操作まで一連の処理を実行できる。

---

## Phase 5：テスト・レビュー

### 実装内容

* テストケースの実施
* 動作確認
* 設計と実装の確認
* 必要に応じて設計を修正

### 完了条件

設計した動作が正常に実行できる。
